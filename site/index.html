时间在栏上，日子在眼前。

菜单栏常驻显示 M月D日 HH:mm:ss。指针移到菜单栏项上，正下方展开当月月历：公历、农历、库内节气与节日，右侧是「此刻」与可左右切换的多时区世界时钟。

功能

只把日历放在该在的位置

01

菜单栏常驻

标题固定为 M月D日 HH:mm:ss，不额外占用 Dock 或桌面窗口。

02

悬停即见

指针移到菜单栏项上，月历在正下方展开；离开后自动收起，也可以点击打开。

03

本地计算

公历、农历、二十四节气与节日都来自本地库；除检查 GitHub Release 更新外不发起网络请求，不上传任何数据。底栏的「检查更新」入口可随时手动检查；自动检查无更新时保持静默，手动检查会提示「已是最新」。0.1.6 起，未签名包也可在应用内下载并校验新版本，重启后完成替换。

说明

当前范围

本轮 GitHub Release 与主页只提供 macOS Intel（x64）的 .dmg。Release 里的 .zip 与同名 .zip.sha256 供应用内自更新使用；0.1.5 及更早版本需手动安装一次 0.1.6。其他平台等验收通过后再扩展。

本地执行 npm run dist 仍可能同时打出 x64 与 arm64 包；GitHub Actions 打出的正式下载目前只有 Intel x64。
