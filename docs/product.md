# 产品功能与范围

栏历是 macOS 菜单栏公历/农历月历。菜单栏常驻显示本地日期时间，指针指向时在正下方展开月历面板；日期计算全部在本机完成。

## 当前功能（0.1.13）

- **菜单栏日期时间**：纯文字 `M月D日 HH:mm:ss`，每秒更新；月日不补零，时分秒补零。默认显示系统本地时间；世界时钟编辑面板的「设为菜单栏」只改变菜单栏显示用的时区（不修改系统时区），菜单栏仍不显示时区名/缩写/标识。
- **悬停弹出月历**：离开约 200ms 收起；点击也能打开，已打开时点击不关闭。
- **月历内容**：公历、农历、库内节气与节日；永远 6×7 格，周一起始。今日为实心橙色圆角格，周末日期与节日/节气小字用红色。
- **顶栏**：左侧大标题为 `YYYY年M月`，点标题用透明叠加的原生 `select` 选年份（1900–2100）；右侧灰色小字为干支生肖年与农历月（如「丙午马年 · 十月」）。右侧依次是上一月、今天、下一月与「⚙︎ 设置」。
- **右侧「黄历」卡片**：按系统本地日期计算，不随翻月、焦点变化，也不随菜单栏显示时区变化。标题行右侧是农历月日（如「十月初九」）；下面「宜」「忌」各一行，分别显示 `getDayYi()` / `getDayJi()` 的前几项（空格连接，单行放不下用省略号截断），悬停 title 显示完整列表；宜用绿色小标签、忌用红色小标签。数据全部来自 lunar-javascript 离线计算，跨天（午夜）随每秒 tick 自动刷新。
- **右侧「世界时钟」卡片**：一次列出全部已添加城市，不再翻页。每行显示城市名、相对本机时区的「今天/昨天/明天 · ±N 小时」小字与大号等宽 `HH:mm`；菜单栏正在显示的时区在城市名后带橙色「菜单栏」标签。城市多时卡片内滚动。标题右侧「编辑」打开编辑面板：上方搜索城市（离线目录 + IANA 回退），下方列出已添加城市，每行可「设为菜单栏」或「移除」；按 IANA id 去重，首次运行默认北京（`Asia/Shanghai`），可删除到空列表。世界时钟列表、索引与菜单栏显示时区写入 `preferences.json`，重启与应用内自更新后保留；若被设为菜单栏显示时区的城市被删除，则回退到系统本地时区。
- **右侧「天气」卡片**：左侧按天气文字显示 emoji，右侧大字温度（如 `17°`）与小字「城市 · 天气」。点击卡片任意位置或标题右侧「更换城市 ›」打开天气城市面板。默认用 ipwho.is 按 IP 定位，城市名直接取 IP 返回结果；天气来自国内 itboy 接口（中国城市，按打包的城市码表换算城市代码）与海外 wttr.in（非中国城市与 itboy 失败时），主源失败自动回退另一源。面板首项为「自动（按 IP）」；搜索框为空时在其下按当前国家（手动城市的 `country`，或自动模式下的 IP 国家）列出内置离线「常用城市」，当前城市标为「已选」，输入搜索词后改为 Open-Meteo 地理编码返回的「城市名 · 省/州 · 国家」；选中后面板立即关闭并显示「城市名 · 加载中…」，城市（含 `country` / `admin1`）保存到 `preferences.json` 的 `weatherCity`，新结果异步推送后更新，选「自动」则删除并回到 IP。结果缓存 30 分钟，打开窗口时过期即刷新，应用运行期间每 30 分钟后台刷新；全部数据源失败才显示「天气暂不可用」，不弹窗、不重试风暴。不提供独立天气设置页。
- **「设置」原生菜单**：点击顶栏「⚙︎ 设置」后，由主进程 `Menu.buildFromTemplate` + `menu.popup` 在按钮下方弹出原生菜单：检查更新（右侧显示当前版本号）、登录时打开（checkbox）、编辑世界时钟…、更换天气城市…、退出栏历（`Cmd+Q`）。菜单打开时设置按钮橙色高亮；检查更新的结果仍在更新横幅区域短暂反馈，更新就绪/手动下载横幅保持不变。
- **导航**：上一月 / 下一月、年份下拉（1900–2100）、点击格子、今天。
- **首次运行**：尝试打开登录项，并记录 `loginItemInitialized`；之后不再强制打开。登录项状态显示在「设置」菜单的「登录时打开」勾选中。系统登录项 API 在未签名包上会失败，此时回退写入本应用自己的 LaunchAgent（`app.lanli.LanLi.plist`），勾选始终反映最终真实状态。
- **离线日历**：农历、节气、节日与月历计算不访问网络；天气（含城市搜索）和打包版的 GitHub Release 更新检查是仅有的网络请求。
- **更新**：0.1.6 起，未签名包也能在应用内下载 zip、校验 sha256、重启后替换旧应用；失败回退到同版本 `.dmg`。
- **平台**：只提供 macOS Intel（x64）；非 macOS 启动会提示「栏历首发只支持 macOS」并退出。

界面尺寸：窗口 `580×400`；左侧月历约 `404px`，右侧卡片栏 `176px`。整体为浅色半透明卡片风格，跟随系统深浅色；窗口不使用透明/vibrancy，只由 CSS 绘制。

## 不做清单

沿用产品范围（旧交接文档中「本轮不做自动更新」已被后续版本撤销）：

- 天气预报详情、多日预报或天气设置页。（右栏只显示当前天气卡片；城市选择在天气面板里完成。）
- 备忘/笔记、通知、提醒、系统日历或日程同步。
- 独立设置窗口或设置页（设置项放在托盘面板内的原生菜单里）、关于窗口。
- 广告或推荐条。
- 佛历、道历、星座、八字。
- `getOtherFestivals` 或任何自建节日表（包括补「光棍节」）。
- 右键菜单、`tray.setContextMenu`、点击切换关闭。
- Windows / Linux 主窗口、Dock 图标、仿菜单栏。
- TypeScript、Vue/React、Webpack/Vite 等前端框架或打包器。
- 第二个日历库，或自写农历/节气算法。
- 使用或仿制 `/Applications/万年历.app` 内的图片、nib、字体、图标；不要反编译该应用。
- 手工主题切换或第二套配色分支；只跟随 `prefers-color-scheme`。
- 本轮代码签名 / 公证 / 上架（仍未签名）。

## 与旧交接文档的差异

0.1.0 的交接规格不在本 git 仓库内，仅作历史对照；当前行为以本文和代码为准：

| 项目 | 旧交接文档 | 当前实现 |
| --- | --- | --- |
| 窗口尺寸 | `680×470` | `580×400` |
| 左/右栏宽 | 500 / 180 | 约 404 / 176（右侧为卡片栏） |
| 菜单栏图标 | `trayTemplate.png` | `Tray(nativeImage.createEmpty())` 纯文字；图片仍在仓库但未引用 |
| 自动更新 | 本轮不做 | 已实现 GitHub 自动更新；0.1.6 起未签名包可应用内自更新 |
| 底栏 | 登录项 + 退出 | 已移除；登录时打开、检查更新、退出栏历移入「设置」原生菜单 |
| 设置入口 | 不做 | 只做顶栏「⚙︎ 设置」原生菜单，不新增窗口或设置页 |
| IPC | 最初的 7 项 | 频道以 [implementation.md](implementation.md) 的完整 IPC 清单为准，其中包含 `app:version`、天气、更新、`menu:openSettings` 与世界时钟相关频道（`clocks:add` 等） |
| 登录项 / 悬停 / 缝隙等真机风险 | 已列 | 行为按规格保留；仍需真机确认，见 [testing.md](testing.md) |

旧文档中已实现但未被后续改写的关键交互（悬停 200ms、Esc 只关面板、42 格规则、次要文字顺序）仍有效。旧的「本轮不做自动更新」不再适用。
