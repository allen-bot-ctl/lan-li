# 产品功能与范围

栏历是 macOS 菜单栏公历/农历月历。菜单栏常驻显示本地日期时间，指针指向时在正下方展开月历面板；日期计算全部在本机完成。

## 当前功能（0.1.13）

- **菜单栏日期时间**：纯文字 `M月D日 HH:mm:ss`，每秒更新；月日不补零，时分秒补零。默认显示系统本地时间；世界时钟卡片的「设为当前」只改变菜单栏显示用的时区（不修改系统时区），菜单栏仍不显示时区名/缩写/标识。
- **悬停弹出月历**：离开约 200ms 收起；点击也能打开，已打开时点击不关闭。
- **月历内容**：公历、农历、库内节气与节日；永远 6×7 格，周一起始。
- **右侧「黄历」**：按系统本地日期计算，不随翻月、焦点变化，也不随菜单栏显示时区变化。第一行是农历干支生肖年与农历月（如「丙午马年·十月」，闰月显示「闰十月」）；下面「宜」「忌」各一行，分别显示 `getDayYi()` / `getDayJi()` 的前几项（空格连接，单行放不下用省略号截断），悬停 title 显示完整列表；宜用绿色系小标签、忌用红色系小标签。数据全部来自 lunar-javascript 离线计算，跨天（午夜）随每秒 tick 自动刷新。
- **右侧「世界时钟」**：一次显示一个时区，城市、`HH:mm:ss`、`M月D日 星期X`；`‹` / `›` 左右切换并绕回，`+` 打开面板内的搜索浮层添加，`×` 删除当前时钟，「设为当前」将该时区设为菜单栏显示用时区（已选中时显示禁用态「当前」）。支持离线城市目录与 IANA 名称回退搜索；按 IANA id 去重。首次运行默认添加北京（`Asia/Shanghai`）；用户可以删除到空列表，空列表显示「点击 + 添加时区」。世界时钟列表、当前索引与菜单栏显示时区写入 `preferences.json`，重启与应用内自更新后保留；若当前被设为菜单栏显示时区的时钟被删除，则回退到系统本地时区。
- **右侧「天气」**：世界时钟下方、版本号分割线上方显示一行 `城市 · 天气 · 温度°C`（如「纽约 · 多云 · 8°C」）。先用 macOS CoreLocation 取当前位置，失败、拒绝或 10 秒超时后回退 IP 定位；城市名来自反向地理编码（city → locality → principalSubdivision），天气来自 Open-Meteo 的当前温度与 WMO 天气代码。结果缓存 30 分钟，打开窗口时过期即刷新，应用运行期间每 30 分钟后台刷新；失败只显示「天气暂不可用」，不弹窗、不重试风暴。不提供设置项。
- **导航**：上一月 / 下一月、年份下拉（1900–2100）、点击格子、返回今天。
- **底栏**：登录时打开开关、检查更新、退出栏历（与检查更新同结构的图标 + 文字按钮）。当前版本号（如 `v0.1.13`）显示在右栏（橙色区域）最底部，上方有一条细分割线。
- **首次运行**：尝试打开登录项，并记录 `loginItemInitialized`；之后不再强制打开。系统登录项 API 在未签名包上会失败，此时回退写入本应用自己的 LaunchAgent（`app.lanli.LanLi.plist`），开关始终显示最终真实状态。
- **离线日历**：农历、节气、节日与月历计算不访问网络；天气和打包版的 GitHub Release 更新检查是仅有的网络请求。
- **更新**：0.1.6 起，未签名包也能在应用内下载 zip、校验 sha256、重启后替换旧应用；失败回退到同版本 `.dmg`。
- **平台**：只提供 macOS Intel（x64）；非 macOS 启动会提示「栏历首发只支持 macOS」并退出。

界面尺寸：窗口 `580×400`；左侧月历 `420px`，右侧橙栏 `160px`。

## 不做清单

沿用产品范围（旧交接文档中「本轮不做自动更新」已被后续版本撤销）：

- 天气预报详情、多日预报、天气设置项或天气城市手动切换。（右栏只显示当前位置的一行当前天气。）
- 备忘/笔记、通知、提醒、系统日历或日程同步。
- 设置页、齿轮入口、关于窗口。
- 广告或推荐条。
- 佛历、道历、星座、八字。
- `getOtherFestivals` 或任何自建节日表（包括补「光棍节」）。
- 右键菜单、`tray.setContextMenu`、点击切换关闭。
- Windows / Linux 主窗口、Dock 图标、仿菜单栏。
- TypeScript、Vue/React、Webpack/Vite 等前端框架或打包器。
- 第二个日历库，或自写农历/节气算法。
- 使用或仿制 `/Applications/万年历.app` 内的图片、nib、字体、图标；不要反编译该应用。
- 第二套主题或为「更像参考图」继续微调出的视觉分支。
- 本轮代码签名 / 公证 / 上架（仍未签名）。

## 与旧交接文档的差异

0.1.0 的交接规格不在本 git 仓库内，仅作历史对照；当前行为以本文和代码为准：

| 项目 | 旧交接文档 | 当前实现 |
| --- | --- | --- |
| 窗口尺寸 | `680×470` | `580×400` |
| 左/右栏宽 | 500 / 180 | 420 / 160 |
| 菜单栏图标 | `trayTemplate.png` | `Tray(nativeImage.createEmpty())` 纯文字；图片仍在仓库但未引用 |
| 自动更新 | 本轮不做 | 已实现 GitHub 自动更新；0.1.6 起未签名包可应用内自更新 |
| 底栏 | 登录项 + 退出 | 增加「检查更新」；当前版本号移至右栏底部 |
| IPC | 最初的 7 项 | 增加的频道以 [implementation.md](implementation.md) 的完整 IPC 清单为准，其中包含 `app:version`、天气、更新，以及世界时钟相关频道（`clocks:add` 等） |
| 底栏高度 | 40px | CSS 中为 32px（随窗口收紧） |
| 登录项 / 悬停 / 缝隙等真机风险 | 已列 | 行为按规格保留；仍需真机确认，见 [testing.md](testing.md) |

旧文档中已实现但未被后续改写的关键交互（悬停 200ms、Esc 只关面板、唯一退出入口、42 格规则、次要文字顺序）仍有效。旧的「本轮不做自动更新」不再适用。
