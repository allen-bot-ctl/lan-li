# 产品功能与范围

栏历是 macOS 菜单栏公历/农历月历。菜单栏常驻显示本地日期时间，指针指向时在正下方展开月历面板；日期计算全部在本机完成。

## 当前功能（0.1.36）

- **菜单栏日期时间**：纯文字 `M月D日 HH:mm:ss`，每秒更新；月日不补零，时分秒补零。默认显示系统本地时间；世界时钟编辑面板的「设为菜单栏」只改变菜单栏显示用的时区（不修改系统时区），菜单栏仍不显示时区名/缩写/标识。
- **悬停弹出月历**：未钉住时离开约 200ms 收起；点击也能打开，已打开时点击不关闭。钉住后托盘鼠标离开、指针离开窗口或窗口失焦都不隐藏。
- **钉住窗口**：顶栏右上角是钉住图标（未钉住时 aria-label「钉住窗口」，悬停 500ms 在按钮正下方显示气泡（与按钮右缘对齐）「钉住窗口，移开鼠标也不隐藏」）。点击后按钮换成 --accent 色 ×，常驻 16% --accent 底色（「取消钉住并关闭」），窗口不再响应托盘/窗口指针离开，也不因失焦隐藏；弹窗仍照常使用。× 与下载、钉住图标同大（14×14 盒子），钉住与否「⚙︎ 设置」位置不变。点 × 或按 Esc 取消钉住并立即隐藏；隐藏后回到未钉住，再次指向菜单栏正常显示。钉住状态只存在内存里，不写入偏好，重启或隐藏后都不保留。
- **月历内容**：公历、农历、库内节气与节日；永远 6×7 格，周一起始。今日为实心橙色圆角格，周末日期与节日/节气小字用红色。
- **通栏顶栏**：窗口最上方 32px，横跨月历与右栏，左右内边距 15px，底部 1px 分隔线。左侧是 16px 应用图标与「栏历」文字（品牌，不是按钮）；右侧从右往左是带文字的「⚙︎ 设置」胶囊（始终最右）、8px、钉住图标、4px、检查更新图标。功能图标 24px、透明底，悬停 --chip-hover，500ms 气泡；以后新增入口继续放在左边。
- **月历顶栏**：左侧大标题为 `YYYY年M月`，后面常驻小「⌄」，悬停出底色与「选择年份」气泡，点标题用透明叠加的原生 `select` 选年份（1900–2100）；左右箭头与「今天」悬停 500ms 分别提示「上个月」「下个月」「回到今天」；右侧灰色小字为干支生肖年与农历月（如「丙午马年 · 十月」，闰月如「闰六月」），按所显示的月份计算：本月取今天，其他月取该月 1 号。翻月区依次是上一月、今天、下一月；钉住、检查更新与设置都在上方通栏顶栏。
- **右侧「黄历」卡片**：0.1.30 起跟随月历里选中的日期（默认今天），不随菜单栏显示时区变化。点月历任一天（含上/下月灰色格，灰色格同时翻到那个月）即选中那天：格子出现 1.5px 强调色描边（今天保持橙色实底、不加描边），卡片按那天计算，标题写成「风格短名 · M月D日」（如「程序猿 · 12月2日」「农历 · 1月1日」）；选中今天时仍是「程序猿黄历」。翻月只换显示的月份、不改选中；点「今天」、窗口收起再打开、或跨午夜时原本选中今天，都回到今天（选中其他日期时跨午夜保持不变）。选中日期不持久化。标题行左侧是风格名，悬停显示农历月日（如「农历十月初九」）；0.1.35 起黄历卡不可点，没有详情面板、「›」、悬停高亮与手形指针。右上角平时留空，指针悬停或键盘聚焦黄历卡时叠放显示「去定制 ›」（120ms 淡入、不占标题宽度，悬停时标题让位）；0.1.31 起选中的不是今天时悬停不显示「去定制 ›」，日期标题始终完整，回到今天后照旧，最长「健身党 · 12月31日」平时一行放下；「去定制 ›」打开「黄历风格」面板。右上角留空与世界时钟卡片标题行一致；节气仍标在月历格子里。卡内三行：宜行与忌行各显示 1 个焦点词（14px 加粗，单行、永不截断），取当日宜/忌里 2000–2099 百年出现天数最少的原词——「无」「诸事不宜」「馀事勿取」三种特殊词不参与挑选（忌列表含「诸事不宜」时直接取它，候选为空时取原列表第一项），「修坟」「安葬」等丧葬类词不过滤；第 3 行是按建除十二值星选取的原创签语（5 种风格各 12 条），0.1.33 起没有「签」字标签，行首是分割线加红漆金边签筒按钮（24×24，悬停提示「重新抽签」）：点一下签筒左右摇晃、一根签弹起，签语换成当前风格 12 条里的另一句（开启「减少动态效果」时不动）。签语有空格就在空格处断成两行，没有空格放得下一行、放不下用均分断成两行，最多 2 行、任何一行不会只有 1 个字、不出省略号；干支日、值星与冲煞不在卡片上显示。宜用绿色小标签、忌用红色小标签，所有风格都不改标签文字与颜色；悬停焦点词只显示稀有度提示（如「年约20次」，没有则不设悬停；农历风格悬停为原词）。数据全部来自 lunar-javascript 离线计算与随包分发的百年稀有度表，跨天（午夜）随每秒 tick 自动刷新。
- **黄历风格**：固定 5 种，顺序为农历黄历、程序猿黄历、打工人黄历、学生党黄历、健身党黄历；默认农历黄历。除农历黄历原样显示外，其余风格把 `getDayYi()` / `getDayJi()` 的每个词条按随包分发的 114 词条映射 JSON 逐词替换，焦点词显示风格文案；卡片只显示焦点词的风格文案，不附「（原词）」对照；0.1.35 起不再有完整宜忌列表面板。映射缺键或值无效时回退为原词；结果只由系统本地日期与所选风格决定，没有随机、打乱或每日轮换。选择写入 `preferences.json` 的 `almanacStyle`，重启与应用内自更新后保留，切换完全离线。
- **右侧「世界时钟」卡片**：一次列出全部已添加城市，不再翻页。每行显示城市名、相对本机时区的小字（本机时区所在城市写「本地」，其他城市写「快 13 小时」「慢 5 小时」，半小时时区如「快 10 小时 30 分」，同偏移写「时间相同」；只显示时差，0.1.35 起不再出现「明天 · 」「昨天 · 」，也不写「今天」；副行一行放下、无省略号）与大号等宽 `HH:mm`；菜单栏正在显示的时区在城市名后带橙色「菜单栏」标签。城市多时卡片内滚动。标题右侧「编辑 ›」默认隐藏，指针悬停或键盘聚焦世界时钟卡时显示，隐藏时保留占位；点击后打开编辑面板：上方搜索城市（离线目录 + IANA 回退），下方列出已添加城市，每行可「设为菜单栏」或「移除」；按 IANA id 去重，首次运行默认北京（`Asia/Shanghai`），可删除到空列表。世界时钟列表、索引与菜单栏显示时区写入 `preferences.json`，重启与应用内自更新后保留；若被设为菜单栏显示时区的城市被删除，则回退到系统本地时区。
- **右侧「天气」卡片**：单行显示：16px 天气 emoji、14px 加粗当前温度（如 `17°`）、紧跟 11px 灰色今日最低~最高气温（如 `12°~20°`，itboy 取 `forecast[0].low/high`、wttr.in 取 `weather[0].mintempC/maxtempC`，取不到时只显示当前温度）、弹性空白（当前温度与区间温度之间 8px 间距）、灰色城市名靠行尾右对齐（如「北京」，加载中/失败时显示状态文字，超长时先隐藏气温区间（卡片加 `.is-compact`，每次渲染天气或切换城市时重新判断，如 Los Angeles 完整显示城市名、北京照常显示区间），隐藏后仍放不下才行尾省略号）。城市名位置默认显示城市，指针悬停或键盘聚焦天气卡时原位 120ms 交叉淡入「更换 ›」，切换时右边缘与垂直位置不变、不推挤温度；「更换 ›」隐藏时保留占位。悬停 title 显示「城市 · 天气」（加载中/失败时为状态文字）。点击整行（含「更换 ›」）打开天气城市面板。默认用 ipwho.is 按 IP 定位，城市名直接取 IP 返回结果；天气来自国内 itboy 接口（中国城市，按打包的城市码表换算城市代码）与海外 wttr.in（非中国城市与 itboy 失败时），主源失败自动回退另一源。面板首项为「自动（按 IP）」；搜索框为空时在其下按当前国家（手动城市的 `country`，或自动模式下的 IP 国家）列出内置离线「常用城市」，当前城市（或「自动（按 IP）」）行显示 `--chip-hover` 底色与右侧强调色 ✓（0.1.36 起不再写「已选」，该行仍可点），输入搜索词后改为 Open-Meteo 地理编码返回的「城市名 · 省/州 · 国家」；选中后面板立即关闭并显示「城市名 · 加载中…」，城市（含 `country` / `admin1`）保存到 `preferences.json` 的 `weatherCity`，新结果异步推送后更新，选「自动」则删除并回到 IP。结果缓存 30 分钟，应用运行期间每 30 分钟后台刷新；系统唤醒（resume）或解锁屏幕后 5 秒强制刷新一次；展开窗口时若上次失败或已超过 30 分钟立即刷新。全部数据源失败时卡片显示「天气不可用」加常显「重试」pill 按钮（22px 高，`--chip-hover` 底，点它只刷新、显示「正在刷新…」，不打开城市面板），不显示「—」占位温度、底色保持正常、「更换 ›」隐藏（点卡片其他位置仍打开城市面板）；失败结果不缓存，失败期间每 60 秒自动重试一次，成功即停；不弹窗。天气城市也可在设置页「天气」页选择，选中态与上面一致。
- **「设置」原生菜单**：点击右上角「⚙︎ 设置」胶囊（带可见文字，aria-label 为「设置」）后，由主进程 `Menu.buildFromTemplate` + `menu.popup` 在按钮正下方左对齐弹出原生菜单：检查更新（右侧显示当前版本号）、开机自启动（checkbox）、黄历风格…、编辑世界时钟…、更换天气城市…、全部设置…、退出栏历（`Cmd+Q`）。「全部设置…」在同一窗口切换到综合设置页（580×432 不变）：左侧 120px 导航依次为界面设置（默认）、黄历、天气、世界时钟、升级，「‹ 返回」与导航之间有 1px 分割线（返回与各导航项同高 30px、手形指针）；进入设置视图后顶栏「⚙︎ 设置」隐藏，钉住与检查更新图标保留。每页顶部有 15px 加粗页标题加分割线，内容区文字不小于 12px。界面设置含「开机自启动」与「菜单栏显示日期」，均为 32×18 拨动开关（开为 --accent，整行可点）（`menuBarShowDate`，默认开，关后菜单栏只显示 `HH:mm:ss`，托盘悬停提示始终为 `YYYY年M月D日 周X`）；黄历页选中的风格行有 `--chip-hover` 底色与右侧 ✓；世界时钟页已添加城市在上、搜索框在下，搜索结果占满剩余高度；升级页显示当前版本，「检查更新」按钮与「今天」同款 pill，下方一行显示上次检查结果（如「已是最新」，没检查过不显示）。「‹ 返回」、Esc 或隐藏窗口后再打开都回到日历视图。菜单打开时按钮橙色高亮；检查更新的结果以通用提示卡片反馈。
- **右栏底部**：只显示「vX.Y.Z」。
- **检查更新图标与通用提示**：顶栏检查更新图标是圆圈加向下箭头（与 App Store「更新」同义，1.5px 描边），与设置菜单走同一检查逻辑；检查/下载中箭头不动、外圈变成一段 90° 弧旋转（1 秒一圈），就绪时右上 6px 橙点。结果显示在顶栏下 8px 居中的通用提示卡片里（宽 320px、最小高 44px、圆角 12px、不透明底，左侧 3px 状态色条，200ms 自上而下淡入、150ms 淡出上移），不占布局、月历不移动；全应用同一时刻只有一条，新的替换旧的。提示分信息（蓝）、成功（绿）、警告（橙）、错误（红）、进行中（底部 2px 流动进度条）五种：「正在检查更新…」「正在下载新版本」为进行中，只被下一个状态替换，30 秒仍无结果转为「检查失败」；「已是最新版本 v0.1.29」「开发态不检查更新」3 秒后消失（悬停时暂停）；「新版本已就绪 · 重启后完成更新＋立即重启」「发现新版本 · 无法自动更新，请手动下载＋下载新版」「检查失败 · 网络不通或更新源暂不可用＋重试」不自动消失，点 × 关闭。
- **导航**：上一月 / 下一月、年份下拉（1900–2100）、点击格子、今天。
- **首次运行**：尝试打开登录项，并记录 `loginItemInitialized`；之后不再强制打开。登录项状态显示在「设置」菜单的「开机自启动」勾选和设置页的同名开关中。系统登录项 API 在未签名包上会失败，此时回退写入本应用自己的 LaunchAgent（`app.lanli.LanLi.plist`），勾选始终反映最终真实状态。
- **离线日历**：农历、节气、节日与月历计算不访问网络；天气（含城市搜索）和打包版的 GitHub Release 更新检查是仅有的网络请求。
- **更新**：0.1.6 起，未签名包也能在应用内下载 zip、校验 sha256、重启后替换旧应用；失败回退到同版本 `.dmg`。
- **平台**：只提供 macOS Intel（x64）；非 macOS 启动会提示「栏历首发只支持 macOS」并退出。

界面尺寸：窗口 `580×432`（32px 通栏顶栏 + 400px 内容）；左侧月历约 `404px`，右侧卡片栏 `176px`。整体为浅色半透明卡片风格，跟随系统深浅色；窗口不使用透明/vibrancy，只由 CSS 绘制。

## 不做清单

沿用产品范围（旧交接文档中「本轮不做自动更新」已被后续版本撤销）：

- 天气预报详情或多日预报。（右栏只显示当前天气卡片；城市选择在天气面板或设置页「天气」页完成。）
- 备忘/笔记、通知、提醒、系统日历或日程同步。
- 独立设置窗口、关于窗口。（设置在同一窗口的综合设置页里，0.1.34 起提供；0.1.36 起设置页左栏「‹ 返回」是与页面标题等高的通栏行、分割线与标题下线连成一条，设置页里「⚙︎ 设置」移除、钉住与更新图标贴右；不做主题色与深浅色手动切换。）
- 广告或推荐条。
- 佛历、道历、星座、八字。
- `getOtherFestivals` 或任何自建节日表（包括补「光棍节」）。
- 右键菜单、`tray.setContextMenu`、点击切换关闭。
- Windows / Linux 主窗口、Dock 图标、仿菜单栏。
- TypeScript、Vue/React、Webpack/Vite 等前端框架或打包器。
- 第二个日历库，或自写农历/节气算法。
- 使用或仿制 `/Applications/万年历.app` 内的图片、nib、字体、图标；不要反编译该应用。
- 手工主题切换或第二套配色分支；只跟随 `prefers-color-scheme`。
- 本轮代码签名 / 公证 / 上架（仍未签名）。

## 与旧交接文档的差异

0.1.0 的交接规格不在本 git 仓库内，仅作历史对照；当前行为以本文和代码为准：

| 项目 | 旧交接文档 | 当前实现 |
| --- | --- | --- |
| 窗口尺寸 | `680×470` | `580×432` |
| 左/右栏宽 | 500 / 180 | 约 404 / 176（右侧为卡片栏） |
| 菜单栏图标 | `trayTemplate.png` | `Tray(nativeImage.createEmpty())` 纯文字；图片仍在仓库但未引用 |
| 自动更新 | 本轮不做 | 已实现 GitHub 自动更新；0.1.6 起未签名包可应用内自更新 |
| 底栏 | 登录项 + 退出 | 登录项与退出已移入「设置」原生菜单；底栏只保留版本号，检查更新在顶栏图标 |
| 设置入口 | 不做 | 右上角「⚙︎ 设置」原生菜单；0.1.34 起「全部设置…」在同一窗口打开综合设置页，不新增窗口 |
| IPC | 最初的 7 项 | 频道以 [implementation.md](implementation.md) 的完整 IPC 清单为准，其中包含 `app:version`、天气、更新、`menu:openSettings` 与世界时钟相关频道（`clocks:add` 等） |
| 登录项 / 悬停 / 缝隙等真机风险 | 已列 | 行为按规格保留；仍需真机确认，见 [testing.md](testing.md) |

旧文档中已实现但未被后续改写的关键交互（悬停 200ms、Esc 只关面板、42 格规则、次要文字顺序）仍有效。旧的「本轮不做自动更新」不再适用。
