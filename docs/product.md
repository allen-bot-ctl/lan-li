# 产品功能与范围

栏历是 macOS 菜单栏公历/农历月历。菜单栏常驻显示本地日期时间，指针指向时在正下方展开月历面板；日期计算全部在本机完成。

## 当前功能（0.1.8）

- **菜单栏本地日期时间**：纯文字 `M月D日 HH:mm:ss`，每秒更新；月日不补零，时分秒补零。
- **悬停弹出月历**：离开约 200ms 收起；点击也能打开，已打开时点击不关闭。
- **月历内容**：公历、农历、库内节气与节日；永远 6×7 格，周一起始。
- **右侧「此刻」**：压缩后的当前星期、公历日（黄色日期块）、干支年 + 生肖、农历月日；不随翻月或焦点变化。本地 `HH:mm` 不再在右栏重复显示（菜单栏已有）。
- **右侧「世界时钟」**：一次显示一个时区，城市、`HH:mm:ss`、`M月D日 星期X`、昨天/明天提示、相对本地时差；`‹` / `›` 左右切换并绕回，`+` 打开面板内的搜索浮层添加，`×` 删除当前时钟。支持离线城市目录与 IANA 名称回退搜索；按 IANA id 去重。首次运行默认添加北京（`Asia/Shanghai`）；用户可以删除到空列表，空列表显示「点击 + 添加时区」。世界时钟列表与当前索引写入 `preferences.json`，重启后保留。
- **导航**：上一月 / 下一月、年份下拉（1900–2100）、点击格子、返回今天。
- **底栏**：登录时打开开关、当前版本号（如 `v0.1.8`）、检查更新、退出栏历。
- **首次运行**：尝试打开登录项，并记录 `loginItemInitialized`；之后不再强制打开。开关始终显示系统读回的真实值。
- **离线日历**：不访问网络；打包版才会检查 GitHub Release 更新。
- **更新**：0.1.6 起，未签名包也能在应用内下载 zip、校验 sha256、重启后替换旧应用；失败回退到同版本 `.dmg`。
- **平台**：只提供 macOS Intel（x64）；非 macOS 启动会提示「栏历首发只支持 macOS」并退出。

界面尺寸：窗口 `580×400`；左侧月历 `420px`，右侧橙栏 `160px`。

## 不做清单

沿用产品范围（旧交接文档中「本轮不做自动更新」已被后续版本撤销）：

- 天气、定位、IP 地理定位，「暂无数据」。（世界时钟只用离线城市目录与 IANA 名称，不读取位置。）
- 备忘/笔记、通知、提醒、系统日历或日程同步。
- 设置页、齿轮入口、关于窗口。
- 广告或推荐条。
- 黄历宜忌、佛历、道历、星座、八字。
- `getOtherFestivals` 或任何自建节日表（包括补「光棍节」）。
- 右键菜单、`tray.setContextMenu`、点击切换关闭。
- Windows / Linux 主窗口、Dock 图标、仿菜单栏。
- TypeScript、Vue/React、Webpack/Vite 等前端框架或打包器。
- 第二个日历库，或自写农历/节气算法。
- 使用或仿制 `/Applications/万年历.app` 内的图片、nib、字体、图标；不要反编译该应用。
- 第二套主题或为「更像参考图」继续微调出的视觉分支。
- 本轮代码签名 / 公证 / 上架（仍未签名）。

## 与旧交接文档的差异

旧规格 `/home/box/mind-workspace/projects/lan-li/appendix/coding-handoff.md` 写于 0.1.0，仅作历史对照；它**不在本 git 仓库内**。以下以当前代码为准：

| 项目 | 旧交接文档 | 当前实现 |
| --- | --- | --- |
| 窗口尺寸 | `680×470` | `580×400` |
| 左/右栏宽 | 500 / 180 | 420 / 160 |
| 菜单栏图标 | `trayTemplate.png` | `Tray(nativeImage.createEmpty())` 纯文字；图片仍在仓库但未引用 |
| 自动更新 | 本轮不做 | 已实现 GitHub 自动更新；0.1.6 起未签名包可应用内自更新 |
| 底栏 | 登录项 + 退出 | 增加「检查更新」与当前版本号 |
| IPC | 最初的 7 项 | 增加 `app:version`、`update:check`、`update:restart`、`update:openLatest`、`update:notice`、`update:status` |
| 底栏高度 | 40px | CSS 中为 32px（随窗口收紧） |
| 登录项 / 悬停 / 缝隙等真机风险 | 已列 | 行为按规格保留；仍需真机确认，见 [testing.md](testing.md) |

旧文档中已实现但未被后续改写的关键交互（悬停 200ms、Esc 只关面板、唯一退出入口、42 格规则、次要文字顺序）仍有效。旧的「本轮不做自动更新」不再适用。
