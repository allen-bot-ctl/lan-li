# 产品功能与范围

栏历是 macOS 菜单栏公历/农历月历。菜单栏常驻显示本地日期时间，指针指向时在正下方展开月历面板；日期计算全部在本机完成。

## 当前功能（0.1.26）

- **菜单栏日期时间**：纯文字 `M月D日 HH:mm:ss`，每秒更新；月日不补零，时分秒补零。默认显示系统本地时间；世界时钟编辑面板的「设为菜单栏」只改变菜单栏显示用的时区（不修改系统时区），菜单栏仍不显示时区名/缩写/标识。
- **悬停弹出月历**：未钉住时离开约 200ms 收起；点击也能打开，已打开时点击不关闭。钉住后托盘鼠标离开、指针离开窗口或窗口失焦都不隐藏。
- **钉住窗口**：左上角是图钉圆钮（未钉住时 aria-label「钉住窗口」，悬停 500ms 在按钮正下方左对齐显示气泡「钉住窗口，移开鼠标也不隐藏」）。点击后按钮换成 ×（「取消钉住并关闭」），窗口不再响应托盘/窗口指针离开，也不因失焦隐藏；弹窗仍照常使用。点 × 或按 Esc 取消钉住并立即隐藏；隐藏后回到未钉住，再次指向菜单栏正常显示。钉住状态只存在内存里，不写入偏好，重启或隐藏后都不保留。
- **月历内容**：公历、农历、库内节气与节日；永远 6×7 格，周一起始。今日为实心橙色圆角格，周末日期与节日/节气小字用红色。
- **通栏顶栏**：窗口最上方 32px，横跨月历与右栏，左右内边距 15px，底部 1px 分隔线。左侧是 24px 图钉圆钮与「栏历」文字；右侧是带文字的「⚙︎ 设置」胶囊。以后新增的入口放在「设置」左边，为 24px 图标圆钮、从右往左排列，各带悬停气泡；本版没有新入口。
- **月历顶栏**：左侧大标题为 `YYYY年M月`，点标题用透明叠加的原生 `select` 选年份（1900–2100）；右侧灰色小字为干支生肖年与农历月（如「丙午马年 · 十月」，闰月如「闰六月」），按所显示的月份计算：本月取今天，其他月取该月 1 号。翻月区依次是上一月、今天、下一月；图钉与设置已移到上方通栏顶栏。
- **右侧「黄历」卡片**：按系统本地日期计算，不随翻月、焦点变化，也不随菜单栏显示时区变化。标题行左侧是当前风格名，悬停显示农历月日（如「农历十月初九」）；右上角平时留空，指针悬停或键盘聚焦黄历卡时显示「去定制 ›」（120ms 淡入、固定占位），切换不跳；「去定制 ›」打开「黄历风格」面板。右上角留空与世界时钟卡片标题行一致；节气仍标在月历格子里。卡内四行：宜行与忌行各显示 1 个焦点词（14px 加粗，单行、永不截断），取当日宜/忌里 2000–2099 百年出现天数最少的原词——「无」「诸事不宜」「馀事勿取」三种特殊词不参与挑选（忌列表含「诸事不宜」时直接取它，候选为空时取原列表第一项），「修坟」「安葬」等丧葬类词不过滤；第 3 行是按建除十二值星选取的原创签语（5 种风格各 12 条，不随机）；第 4 行是「干支日 值星（或节气） 冲X煞Y」底注。宜用绿色小标签、忌用红色小标签，所有风格都不改标签文字与颜色；悬停焦点词显示「文案（原词）」。点击卡片（「去定制 ›」除外）打开「今日黄历」面板。数据全部来自 lunar-javascript 离线计算与随包分发的百年稀有度表，跨天（午夜）随每秒 tick 自动刷新。
- **黄历风格**：固定 5 种，顺序为农历黄历、程序猿黄历、打工人黄历、学生党黄历、健身党黄历；默认农历黄历。除农历黄历原样显示外，其余风格把 `getDayYi()` / `getDayJi()` 的每个词条按随包分发的 114 词条映射 JSON 逐词替换，焦点词显示风格文案、悬停显示「文案（原词）」；完整宜忌列表在「今日黄历」面板里按替换后的文案去重（保留首次出现）并写作「文案（原词）」。映射缺键或值无效时回退为原词；结果只由系统本地日期与所选风格决定，没有随机、打乱或每日轮换。选择写入 `preferences.json` 的 `almanacStyle`，重启与应用内自更新后保留，切换完全离线。
- **「今日黄历」面板**：点击黄历卡片打开（点「去定制 ›」仍打开黄历风格面板）。标题为「今日黄历 · 十月初九」，主体六段依次为：今日焦点（宜/忌焦点词，附稀有度提示如「年约20次」或「不到一年一次」）、宜（N）、忌（N）（全部词条空格连接、自动换行）、签语（为空时不显示）、建除 · 值神 · 冲煞、彭祖百忌。只能用右上「完成」关闭；打开世界时钟、天气城市或黄历风格面板时自动关闭。内容来源与卡片相同，面板打开期间跨天会随 tick 立即重绘。
- **右侧「世界时钟」卡片**：一次列出全部已添加城市，不再翻页。每行显示城市名、相对本机时区的「今天/昨天/明天 · ±N 小时」小字与大号等宽 `HH:mm`；菜单栏正在显示的时区在城市名后带橙色「菜单栏」标签。城市多时卡片内滚动。标题右侧「编辑 ›」默认隐藏，指针悬停或键盘聚焦世界时钟卡时显示，隐藏时保留占位；点击后打开编辑面板：上方搜索城市（离线目录 + IANA 回退），下方列出已添加城市，每行可「设为菜单栏」或「移除」；按 IANA id 去重，首次运行默认北京（`Asia/Shanghai`），可删除到空列表。世界时钟列表、索引与菜单栏显示时区写入 `preferences.json`，重启与应用内自更新后保留；若被设为菜单栏显示时区的城市被删除，则回退到系统本地时区。
- **右侧「天气」卡片**：单行显示：16px 天气 emoji、14px 加粗温度（如 `17°`）、弹性空白、灰色城市名靠行尾右对齐（如「北京」，加载中/失败时显示状态文字，超长时行尾省略号）。城市名位置默认显示城市，指针悬停或键盘聚焦天气卡时原位 120ms 交叉淡入「更换 ›」，切换时右边缘与垂直位置不变、不推挤温度；「更换 ›」隐藏时保留占位。悬停 title 显示「城市 · 天气」（加载中/失败时为状态文字）。点击整行（含「更换 ›」）打开天气城市面板。默认用 ipwho.is 按 IP 定位，城市名直接取 IP 返回结果；天气来自国内 itboy 接口（中国城市，按打包的城市码表换算城市代码）与海外 wttr.in（非中国城市与 itboy 失败时），主源失败自动回退另一源。面板首项为「自动（按 IP）」；搜索框为空时在其下按当前国家（手动城市的 `country`，或自动模式下的 IP 国家）列出内置离线「常用城市」，当前城市标为「已选」，输入搜索词后改为 Open-Meteo 地理编码返回的「城市名 · 省/州 · 国家」；选中后面板立即关闭并显示「城市名 · 加载中…」，城市（含 `country` / `admin1`）保存到 `preferences.json` 的 `weatherCity`，新结果异步推送后更新，选「自动」则删除并回到 IP。结果缓存 30 分钟，打开窗口时过期即刷新，应用运行期间每 30 分钟后台刷新；全部数据源失败才显示「天气暂不可用」，不弹窗、不重试风暴。不提供独立天气设置页。
- **「设置」原生菜单**：点击右上角「⚙︎ 设置」胶囊（带可见文字，aria-label 为「设置」）后，由主进程 `Menu.buildFromTemplate` + `menu.popup` 在按钮正下方左对齐弹出原生菜单：检查更新（右侧显示当前版本号）、登录时打开（checkbox）、黄历风格…、编辑世界时钟…、更换天气城市…、退出栏历（`Cmd+Q`）。菜单打开时按钮橙色高亮；检查更新的结果仍在更新横幅区域短暂反馈，更新就绪/手动下载横幅保持不变。
- **右栏底部**：居中显示「栏历 vX.Y.Z」；右侧以「·」分隔 10px 的「检查更新」文字按钮，平时用 `--muted`（比版本号的 `--faint` 深一级），悬停变 `--link`；它不受卡片悬停规则影响、始终可见。点击后走与设置菜单相同的检查逻辑，反馈仍在更新横幅区域，设置菜单里的入口保留。
- **导航**：上一月 / 下一月、年份下拉（1900–2100）、点击格子、今天。
- **首次运行**：尝试打开登录项，并记录 `loginItemInitialized`；之后不再强制打开。登录项状态显示在「设置」菜单的「登录时打开」勾选中。系统登录项 API 在未签名包上会失败，此时回退写入本应用自己的 LaunchAgent（`app.lanli.LanLi.plist`），勾选始终反映最终真实状态。
- **离线日历**：农历、节气、节日与月历计算不访问网络；天气（含城市搜索）和打包版的 GitHub Release 更新检查是仅有的网络请求。
- **更新**：0.1.6 起，未签名包也能在应用内下载 zip、校验 sha256、重启后替换旧应用；失败回退到同版本 `.dmg`。
- **平台**：只提供 macOS Intel（x64）；非 macOS 启动会提示「栏历首发只支持 macOS」并退出。

界面尺寸：窗口 `580×432`（32px 通栏顶栏 + 400px 内容）；左侧月历约 `404px`，右侧卡片栏 `176px`。整体为浅色半透明卡片风格，跟随系统深浅色；窗口不使用透明/vibrancy，只由 CSS 绘制。

## 不做清单

沿用产品范围（旧交接文档中「本轮不做自动更新」已被后续版本撤销）：

- 天气预报详情、多日预报或天气设置页。（右栏只显示当前天气卡片；城市选择在天气面板里完成。）
- 备忘/笔记、通知、提醒、系统日历或日程同步。
- 独立设置窗口或设置页（设置项放在托盘面板内的原生菜单里）、关于窗口。
- 广告或推荐条。
- 佛历、道历、星座、八字。
- `getOtherFestivals` 或任何自建节日表（包括补「光棍节」）。
- 右键菜单、`tray.setContextMenu`、点击切换关闭。
- Windows / Linux 主窗口、Dock 图标、仿菜单栏。
- TypeScript、Vue/React、Webpack/Vite 等前端框架或打包器。
- 第二个日历库，或自写农历/节气算法。
- 使用或仿制 `/Applications/万年历.app` 内的图片、nib、字体、图标；不要反编译该应用。
- 手工主题切换或第二套配色分支；只跟随 `prefers-color-scheme`。
- 本轮代码签名 / 公证 / 上架（仍未签名）。

## 与旧交接文档的差异

0.1.0 的交接规格不在本 git 仓库内，仅作历史对照；当前行为以本文和代码为准：

| 项目 | 旧交接文档 | 当前实现 |
| --- | --- | --- |
| 窗口尺寸 | `680×470` | `580×432` |
| 左/右栏宽 | 500 / 180 | 约 404 / 176（右侧为卡片栏） |
| 菜单栏图标 | `trayTemplate.png` | `Tray(nativeImage.createEmpty())` 纯文字；图片仍在仓库但未引用 |
| 自动更新 | 本轮不做 | 已实现 GitHub 自动更新；0.1.6 起未签名包可应用内自更新 |
| 底栏 | 登录项 + 退出 | 登录项与退出已移入「设置」原生菜单；底栏只保留版本号与「检查更新」入口 |
| 设置入口 | 不做 | 只做右上角「⚙︎ 设置」原生菜单，不新增窗口或设置页 |
| IPC | 最初的 7 项 | 频道以 [implementation.md](implementation.md) 的完整 IPC 清单为准，其中包含 `app:version`、天气、更新、`menu:openSettings` 与世界时钟相关频道（`clocks:add` 等） |
| 登录项 / 悬停 / 缝隙等真机风险 | 已列 | 行为按规格保留；仍需真机确认，见 [testing.md](testing.md) |

旧文档中已实现但未被后续改写的关键交互（悬停 200ms、Esc 只关面板、42 格规则、次要文字顺序）仍有效。旧的「本轮不做自动更新」不再适用。
