# 0.1.51 屏幕录制授权修复（老板 02:38 真机反馈）

## 问题
1. 点说明卡「打开系统设置」后，说明卡不消失。
2. 系统设置「屏幕录制」列表里看不到栏历。根因：`region-capture.js` 的 `open()` 只看了 `getMediaAccessStatus`，不是 granted 就直接弹自家说明卡并 return，从来没调过 `desktopCapturer.getSources`。macOS 要等应用**真的尝试截屏**，才会弹系统授权框、把应用登记进列表。EasyLens feat/gbot `electron/main.js` 813–818 行的注释写的就是这条：不要预检后跳过截屏。

## 改法（唯一方案）
1. `open()` 遇到权限不是 granted 时，先调一次 `desktopCapturer.getSources({ types: ['screen'], thumbnailSize: { width: 1, height: 1 } })` 来登记应用（套 1500ms 超时，超时或报错都吞掉，只写日志），然后**再判断一次**权限：
   - 变成 granted：直接进框选层，不弹说明卡；
   - 仍不是 granted：弹自家说明卡。
   每次按 ⌃⌥S、点托盘「框选收纳」都走这一步。系统授权框只在第一次出现，之后 macOS 不会再弹，不会打扰。
2. 点「打开系统设置」：先打开设置页，再**立刻关掉说明卡**。点「知道了」、按 Esc 也关闭说明卡。
3. 说明卡文案（最长一行 ≤ 说明卡现有宽度，不加宽）：
   - 标题：需要屏幕录制权限
   - 正文：框选收纳要截取你框住的那一块画面，不会上传。
   - 步骤：在「屏幕录制」列表里打开「栏历」的开关，按提示重新打开栏历。
   - 小字（灰）：列表里没有栏历？点列表下方的「+」，在「应用程序」里选「栏历」。
   - 按钮：知道了｜打开系统设置（主按钮）
4. 日志：`[栏历] 框选：权限 <before> → 登记截屏 → <after>`，以后查问题用。

## 验收
- P-C1 e2e：权限设为 denied 时按 ⌃⌥S，`getSources` 被调用 1 次，然后才出说明卡（用 spy 计数）。
- P-C2 e2e：登记后权限变成 granted（e2e 钩子模拟），直接进框选层，不出说明卡。
- P-C3 e2e：点「打开系统设置」后，openCalls 为 1，说明卡窗口已关闭；「知道了」和 Esc 也能关。
- P-C4 截图：57 号说明卡深浅两套重拍，新增的小字不能截断。
- 真机（老板）：升级后第一次按 ⌃⌥S，系统会弹出授权框，或者「屏幕录制」列表里已经有栏历；打开开关、重新打开栏历后，再按 ⌃⌥S 能直接框选。

## 不做
不改签名方式；不做轮询自动检测授权。
