# 0.1.34 综合设置页 · 契约

需求原话：设置下拉里加「更多」，点进去在同一个窗口里切换到综合设置页，用左侧导航，默认打开「界面设置」。界面设置这一版只做开机自启动和菜单栏是否显示日期。黄历、天气、世界时钟、升级几页把现有设置搬进来。
样稿：不出。布局在本文写死，coder 照做。构建用 GitHub CI。编码主力用 MiMo Code，要记录用时和返工次数。

## 锁定
1. **入口**
   - ⚙︎ 下拉菜单原有各项都保留，在「退出栏历」前那条分隔线上面加一项「更多…」。
   - 下拉菜单里的「登录时打开」改名为「开机自启动」，和设置页的叫法一致。
2. **视图**
   - 点「更多…」后在当前窗口切换到设置视图，窗口保持 580×432 不变。
   - 32px 的顶栏不动；顶栏下面的区域整块换成设置视图。
   - 设置视图左边是 120px 宽的导航，右边是内容区。
   - 导航最上面放「‹ 返回」按钮。按它或按 Esc 回到日历视图。
   - 窗口隐藏后再打开，一律回到日历视图。
3. **导航**
   - 顺序：界面设置、黄历、天气、世界时钟、升级。
   - 每次进入设置页，默认选中「界面设置」。
   - 选中项的样式沿用现有的选中态，用 `--chip-hover` 底色加 `--text` 文字色。
4. **界面设置**：两行开关，左边是名称，右边是开关。
   - 「开机自启动」
     - 开关读写 `app.getLoginItemSettings` / `setLoginItemSettings`，和下拉菜单里那一项是同一个状态。
     - 默认值沿用现在的行为：不主动打开。
   - 「菜单栏显示日期」
     - 默认开。开时显示现有格式 `M月D日 HH:mm:ss`。
     - 关时只显示 `HH:mm:ss`，时区规则和现在一样。
     - 存进 preferences.json，字段名 `menuBarShowDate`，类型是布尔值，字段缺失按 true 处理。
     - 切换后下一秒就生效，重启后保持。
     - 关掉日期后，鼠标移到菜单栏上照常展开日历，日历里能看到当天日期，不另加悬停提示。
     - `MENU_TITLE_PATTERN` 要同时接受这两种格式。
5. **黄历 / 天气 / 世界时钟**
   - 这三页里直接放现有面板的内容：「选择黄历风格」「选择天气城市」「编辑世界时钟」。
   - 用同一套组件和数据，改动立即生效。
   - 下拉菜单里原有的三个入口照常打开原来的面板。
6. **升级**
   - 一行「当前版本 0.1.34」，取 `app.getVersion()`。
   - 下面放一个「检查更新」按钮，走现有的检查更新流程，结果用现有的提示卡片显示。
7. **不做**：主题色、深浅色、新增设置项。不改日历视图的布局。

## coder 可以自己定的
开关的视觉样式（用系统风格的拨动开关或复选框都行）、内容区边距、切换视图的动画（动画不超过 150ms，也可以不做动画）、组件怎么复用。

## 验收（e2e 必须真点、真切换，期望值靠计算得出，不许写死）
- C1：下拉菜单模板里有「更多…」，位置在「退出栏历」前那条分隔线上面；原来的「登录时打开」已改名为「开机自启动」。点「更多…」后显示设置视图，窗口尺寸仍是 580×432。
- C2：导航按顺序是「界面设置、黄历、天气、世界时钟、升级」，进入时选中「界面设置」。
- C3：在设置页点开「开机自启动」后，setLoginItemSettings 收到 `openAtLogin: true`，下拉菜单模板里这一项也变成勾选；关掉时同样检查。
- C4：关掉「菜单栏显示日期」后，托盘标题匹配 `^\d{2}:\d{2}:\d{2}$`，并且等于当前时间按菜单栏时区格式化出的结果；打开后恢复成 `M月D日 HH:mm:ss`。preferences.json 里 `menuBarShowDate` 变成 false；重启后标题仍然只显示时间。
- C5：在「黄历」页换一种风格，返回后黄历卡上的风格名变成新的。在「世界时钟」页加一个城市，返回后时钟卡多出这一行。在「天气」页选一个城市（网络用 mock），返回后天气卡上的城市变成新选的。
- C6：「升级」页显示的版本号等于 app.getVersion()；点「检查更新」会走现有流程，并弹出提示卡片。
- C7：在设置视图里按「‹ 返回」、按 Esc、把窗口隐藏再打开，这三种情况都回到日历视图。
- C8：现有的单测和 e2e 全部通过。下拉菜单里原有的三个面板入口照常可用。
