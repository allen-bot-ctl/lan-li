# 0.1.54 世界时钟跨天显示日期 + 年月下拉箭头（老板 2026-11-22 02:28 北京时间）

## 1. 世界时钟：跨天时显示所在日期
**现状**：城市下方一律显示「快/慢 N 小时」（`electron/world-clocks.js` `describeClockRelative`，第 216 行起）。比如纽约 11/21 13:24 时，北京已经是 11/22 02:24，却还写着「快 13 小时」，看不出已经是第二天。

**规则**：比较「该城市所在时区的日期」和「本机时区的日期」，即现有的 `dayDelta`。

| 情况 | 城市下方文字 | 例子（本机是纽约 11/21 13:24） |
|---|---|---|
| 就是本机时区 | `本地`（不变） | 纽约 → 本地 |
| 同一天，时区不同 | `快/慢 N 小时`（不变；半小时时区仍写「N 小时 M 分」） | 洛杉矶 → 慢 3 小时 |
| 同一天，偏移为 0 | `时间相同`（不变） | — |
| 不在同一天（明天或昨天） | 该城市的日期，格式 `月/日`，不补零 | 北京 → `11/22`；东京 → `11/22`；若本机在北京，纽约 → `11/21` |

- 跨天时**只**显示日期，不再显示快/慢，也不加「明天/昨天」字样。
- 右侧时间、「菜单栏」标签、字号和颜色都不变。日期沿用现在「快 13 小时」那一行的样式。
- 跨过午夜要随时钟刷新：本机或该城市过 0 点后，最迟一分钟内文字要切换。
- 改法：`describeClockRelative` 的 `text` 在 `dayDelta !== 0` 时返回 `${zone.month}/${zone.day}`，其余分支不动。

## 2. 年月旁的下拉箭头
**现状**：`calendar.html:79` 用的是文字字符 `⌄`，`.month-title-caret` 为 10px（`calendar.css:268`）。字符又窄又小，位置偏下。

**改为**：一个内联 SVG 向下箭头，替换掉 `⌄`。
- viewBox `0 0 12 8`，路径 `M1.5 1.75 L6 6.25 L10.5 1.75`，线宽 `stroke-width:1.8`，`stroke-linecap:round`，`stroke-linejoin:round`，无填充。
- 显示尺寸 12×8px，颜色 `currentColor`，取自 `--muted-strong`，深浅两套主题都跟随。
- 与「2026年11月」文字左间距 6px，箭头垂直中心对齐文字的中线（汉字高度的中间），不是基线。
- 悬停时整块 `.month-title` 的底色照旧，点击仍打开年份选择，`aria-hidden` 不变。
