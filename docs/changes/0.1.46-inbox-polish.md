# 0.1.46 收纳打磨（老板 23:07 反馈 1–4）

## 产品逻辑
- 顶栏「‹ 返回」那一行 = 路由层，告诉你「在哪个页面」：左返回、标题居中、右侧放计数等附加信息。所有二级页一致。
- 内容区里的标题 = 内容层，告诉你「这一块是什么」：左对齐。
- 收纳是「过去收进来的东西」，日期筛选看的是一段时间，不存在未来。

## 改动
1. 顶栏图标间距：收纳、更新、钉住三个图标按钮同尺寸，中心距统一（现状 收纳→更新 24px、更新→钉住 28.5px，统一为 28px）；与「设置」胶囊的间距同为 8px 外边距；垂直居中。
2. 空状态：提示文字（加 24px 单色收纳图标在上）在列表区域（筛选栏下沿到窗口底）内水平、垂直居中。筛选后为空同样居中，文案「没有符合条件的收纳」+「清除筛选」。
3. 二级页标题统一：设置页顶栏改为「‹ 返回 | 设置（居中）」；右侧内容区的「界面设置」等保留为左对齐的内容标题，字号比顶栏标题小一级。收纳页不变。
4. 日期筛选改为「时间范围」：
   - 📅（单色图标）点开弹层，上方快捷项：今天 / 最近 7 天 / 最近 30 天 / 全部时间；下方小月历选自定义区间：先点起点、再点终点，区间高亮；只点一个日期再点外面 = 当天。
   - 有收纳的日期下方显示小圆点；今天之后的日期置灰不可点。
   - 选定后弹层立即关闭，列表直接显示结果；筛选栏出现胶囊「11月1日–11月19日 ×」（快捷项显示「最近 7 天 ×」）。
   - 弹层只盖在列表上方、不推挤列表；点外面或 Esc 关闭。

## 验收
- P-C1 三个图标中心距相等（±1px），与胶囊间距 8px。
- P-C2 空状态、筛选空状态文字中心与列表区域中心偏差 ≤2px。
- P-C3 设置页和收纳页顶栏标题都水平居中（±1px），设置内容标题左对齐。
- P-C4 快捷项四种、区间选择、单日选择都能筛对；未来日期不可点；选完弹层关闭；胶囊文案正确；× 清除。
- P-C5 e2e 补截图：44-topbar-icons、45-inbox-empty、46-settings-header、47-date-range-popover、48-date-range-result。
