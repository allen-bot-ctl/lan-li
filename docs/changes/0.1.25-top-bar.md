# CONTRACT · 0.1.25 通栏顶栏（mind，2026-11-17）

## 要做什么
窗口最上方加一条通栏顶栏：左上角图钉和「栏历」，右上角「⚙ 设置」，中间留给以后的入口。月历顶栏只保留年月和翻月。

## 布局（数值只写这里）
- 顶栏：高 32px，横跨整个窗口宽度 580px；左右内边距与月历栏一致（15px）；底部 1px 分隔线，颜色 --pane-line；背景与窗口相同，不加卡片。
- 窗口高度 400 → 432（只加顶栏的 32px）；宽度不变。月历栏、右栏的内部尺寸和间距全部不变。
- 左组：图钉圆钮（24px，沿用 0.1.24 样式和交互）＋ 间距 6px ＋「栏历」文字（13px，600，--text）。
- 右组：「⚙ 设置」胶囊（沿用 0.1.23 的 nav-pill 样式：高 26px，12px，500 字重，带「设置」文字）。点击弹出原有原生菜单，菜单位置跟着按钮走（按钮正下方，左缘对齐）。
- 以后新增的入口：24px 图标圆钮，放在「设置」左边，从右往左排，间距 6px，每个带悬停提示气泡（沿用 0.1.24 气泡）。本版不加新入口。
- 月历顶栏：只剩年月标题、农历副标题和 ‹ 今天 ›；齿轮和图钉从这里移走。

## 交互
- 图钉：与 0.1.24 完全一致（提示文案、×、Esc、不持久化、失焦不隐藏）。气泡改为在按钮下方、左对齐，不超出窗口。
- 设置：悬停不再需要提示气泡（有文字）；菜单展开时窗口保持打开（现有逻辑）。
- 顶栏区域算作窗口的一部分：鼠标在顶栏上不触发隐藏。
