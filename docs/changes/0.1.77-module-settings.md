# 收纳、日历与大模型设置

- 「收纳」设置包含「日历联动」和「标签」两组。联动默认开启；旧偏好中字段缺失仍按开启处理。
- 关闭联动只移除日历主页的收纳快捷入口、日期标记及按日跳转。不删除收纳，不改标签，也不影响独立收纳内的日期筛选。系统托盘的「收纳」仍可打开独立收纳。
- `settings:get` 返回 `inboxDateLinkEnabled`；`settings:setInboxDateLinkEnabled` 接受布尔值并保留其他偏好；写入成功后，通过 `settings:inboxDateLinkChanged` 同步当前界面。保存失败恢复原开关状态。
- 「大模型」与「帮阅」同级。模型地址、名称、密钥以及测试、保存和清除仍使用原有配置接口。旧配置不用迁移。帮阅读取配置状态，只在未配置或不可用时禁用依赖模型的操作；本地手工编辑及恢复提示词不依赖模型。
