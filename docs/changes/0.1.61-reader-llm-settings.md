# 0.1.61 帮阅：去掉 EasyLens 关联，未配置 Key 时明确提示

来源：老板 2026-11-23 05:59 ET 真机验收 0.1.60：「我是会分发给其他用户使用的，没必要和 EasyLens 强关联；可以有必要的报错，例如未配置大模型等，然后我去配置就行了。」
范围按 PM 06:01 定的 5 条（本文件以此为准，取代 7a4688d/5b0231d 的三项设置版）。

1. 删掉读取 `~/.easylens/deepseek-api-key` 的全部代码（含 `easylensDir` 配置和 e2e 环境变量），删掉设置里「正在使用 EasyLens 的 DeepSeek Key」这一行。界面和发版说明里不再出现 EasyLens。老数据不迁移。
2. 设置的帮阅页只保留 Key 输入框、「保存」「删除 Key」。状态行（12px 灰字）：有 Key 显示「已配置」，没有显示「未配置大模型 Key」。
3. 没配 Key 时在帮阅页提交网址：输入框下方提示「未配置大模型 Key」，后面跟一个「去设置」按钮，点了打开设置的帮阅 tab。这时不抓取，也不生成历史记录。
4. Key 无效、额度不足等情况，沿用 0.1.60 的报错分类，在那条记录上显示原因和「重试」。
5. 删掉 EasyLens 相关的单测；第 3 条补单测和 e2e 各一条。

## 验收
- R1 单测：即使存在 `~/.easylens/deepseek-api-key` 也不会读取；没有 Key 时提交，返回「未配置」，不入队，也不写 `userData/read/`。
- R2 e2e：没有 Key 时提交网址，出现「未配置大模型 Key」和「去设置」，点了进入设置的帮阅 tab，列表没有新增行；填好 Key 保存后，状态行显示「已配置」。
- R3 截图（深浅各一套）：`61-settings-reader-empty`、`61-settings-reader-ok`、`61-reader-no-key`。
- M1 老板真机：设置里没有 EasyLens 字样；粘贴自己的 Key 后能读完一篇。
