# 0.1.49 收纳：非文件内容的收入方式（老板 01:16）

## 判断
- 拖拽只适合文件。macOS 菜单栏图标能接的拖拽类型有限：从浏览器拖选中文字，最多拿到纯文本，拿不到图文和格式；很多应用（微信、飞书等）根本不允许把选中内容拖出来。所以文字、图文、链接的主路径改为「复制 → 收」，拖拽保留为附加方式。
- 收的是剪贴板，不需要辅助功能权限；我们不去「读取当前选中内容」（那要辅助功能授权，且各应用表现不一）。

## 方案（一次做齐三个入口，背后同一个函数 saveClipboard）
1. 全局快捷键 ⌥⌘V：在任何应用里先 ⌘C，再按 ⌥⌘V，就把剪贴板收进来；菜单栏下方弹出接纳框成功态「已收纳 · 文字/图文/链接/图片」，1.2s 消失。快捷键被其他应用占用时，设置页显示「快捷键被占用」并允许关闭。
2. 收纳面板里按 ⌘V（焦点不在搜索框时），或点面板顶栏新增的「粘贴收纳」按钮。
3. 托盘右键菜单新增「收纳剪贴板内容  ⌥⌘V」，放在「设置中心…」上方。
- 剪贴板判型（按优先级）：文件 URL → 文件；图片 → 图片；HTML → 图文（沿用 content.html + assets/ 规则）；纯文本且整体是一个 http(s) 链接 → 链接（抓标题，失败用域名）；其他纯文本 → 文字。
- 空剪贴板或不支持：错误态「剪贴板里没有可收纳的内容」。
- 同一内容 3 秒内重复收，只存一份，提示「已经收过了」。
