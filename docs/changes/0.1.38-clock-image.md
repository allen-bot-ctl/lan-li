# 栏历 v0.1.38 契约：菜单栏时钟画成图片

来源：老板 03:08 问栏历间距是否已到极限；PM 03:11 定稿；coder 在老板 Mac 实测：文字标题 77pt，画成图片 73pt（`03:10:25`，13pt 菜单栏字体，文字本身 56.2pt）。

## 做什么
- 托盘时钟从文字标题改为每秒画一张模板图片（`setTemplateImage(true)`），字体、字号、内容和现在一致，深色/浅色由系统自动着色。
- 悬停提示、点击打开面板等行为不变。

## 验收
- M1：在老板 Mac 上量托盘真实宽度，比文字版少约 4pt（77 → 73pt）。
- M2：CPU 占用比文字版高不超过 0.5 个百分点，实测数写进日志。不达标就不发，在群里报数据。
- M3：截图看 1x、2x 下字不糊、不偏上下，深色和浅色各一张。
- M4（老板真机）：配合栏况 0.1.9，时钟左边到栏况约 37px（2x）。
