## 1. 去掉「⚙ 设置」下拉菜单，点了直接进设置页

- 日历、收纳、帮阅三页顶栏的「⚙ 设置」点了就直接打开设置页。效果和原来菜单里的「全部设置…」完全一样（main 里的 `openMore`：`keepWindowOpen = true; sendPanel('settings')`），进入后按 0.1.62 的规则自动钉住。
- 删掉原生下拉菜单：`openSettingsMenu`、`buildSettingsMenuTemplate`、`settingsMenuOpen` 及相关判断、e2e 的 `settingsMenuItems` 测试钩子，以及 ⚙ 按钮的 `is-open` / `aria-expanded` 状态。
- 菜单里原来的各项在设置页都有入口，不用另外补：

| 原菜单项 | 去处 |
|---|---|
| 检查更新 | 设置 › 升级；托盘右键「检查更新…」 |
| 开机自启动 | 设置 › 界面设置 |
| 黄历风格…、编辑世界时钟…、更换天气城市… | 设置 › 黄历 / 世界时钟 / 天气 |
| 全部设置… | 就是 ⚙ 本身 |
| 退出栏历 | 设置页右上角（第 2 条）；托盘右键「退出栏历」 |

- 设置页本身仍然不显示 ⚙（N4 不变）。

## 2. 设置页右上角「退出栏历」，点了弹框确认

### 2.1 按钮

- 位置：设置页标题行（「‹ 返回 · 设置」那一行）最右边，就是截图 2 的红框，和「‹ 返回」在同一条水平中线上。
- 样式：文字按钮「退出栏历」，13px，颜色 `var(--red)`，高 36px，左右内边距 16px，不带边框。悬停时背景 `var(--chip)`，手型光标；键盘聚焦时显示 2px 强调色描边，样式和 `.settings-back` 一致。
- 设置页各个分页（界面设置……升级）都显示这个按钮，位置不变。

### 2.2 确认弹框（窗口内部的弹层，不用系统对话框）

- 遮罩盖住整个窗口，颜色 `rgba(0,0,0,.35)`。卡片宽 280px，圆角 12px，内边距 20px，背景和设置页面板一致。深浅两套都要看。
- 标题「确定退出栏历吗？」：15px，semibold，正文色。
- 说明「退出后，菜单栏时钟、快捷键和框选收纳都会停用。要再使用，需要从「应用程序」里重新打开栏历。」：13px，次级色，行高 1.6。
- 按钮右对齐：
  - 「取消」：次级 nav-pill 样式。
  - 「退出」：`var(--red)` 实底、白字、圆角，高度和「取消」一样。
  - 两个按钮间距 8px。
- 弹出时默认聚焦「取消」，按回车只会触发当前聚焦的按钮，避免误退出。
- 点「退出」后，调用现有的 `quitWithFallback()`（和托盘「退出栏历」、自更新同一个退出函数）。

| 状态 | 屏幕上 |
|---|---|
| 设置页（任一分页） | 右上角显示「退出栏历」 |
| 点「退出栏历」 | 出现遮罩和确认卡片，焦点在「取消」 |
| 点「取消」、按 Esc 或点遮罩空白处 | 弹框关闭，留在设置页原来的分页。Esc 只关弹框，不会同时退回日历 |
| 点「退出」 | 应用退出，窗口和菜单栏时钟消失 |
| 弹框开着时点菜单栏时钟 | 窗口隐藏，弹框一起关掉；下次打开不带弹框 |
| 弹框开着时，帮阅正在读或者有下载在进行 | 照常退出，不再多问 |

- 托盘右键菜单的「退出栏历」和 ⌘Q 保持现状，不加确认（PM 22:16）：右键菜单本身就是一次明确的选择，符合 macOS 菜单「退出」的惯例。
