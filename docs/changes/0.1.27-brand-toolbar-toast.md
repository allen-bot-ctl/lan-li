  - 已是最新（✓，--muted-strong）：2.5 秒后自动消失。
  - 开发态不检查更新：2.5 秒后自动消失。

- 新版本提示优先：已有就绪提示时，手动检查的状态不覆盖它（沿用现有逻辑）。
