# 0.1.26：月历副标题跟随所显示的月份

## 规则
- 月历顶栏副标题（干支生肖年 · 农历月，如「丙午马年 · 十月」「乙巳蛇年 · 闰六月」）按**所显示的月份**计算：
  - 显示的是本月：取今天（跨午夜随 tick 更新）。
  - 显示的是其他月份：取该月 1 号。
- 右侧黄历卡不变，仍按今天计算，不随翻月变化。

## 验收
- S1 从本月翻到 2025年7月，副标题为 2025-07-01 对应的「乙巳蛇年 · 六月」；再翻回本月，副标题回到今天的值；等待 2 秒（经过 tick）后不被今天的值覆盖。
- S2 年份下拉直接选到别的年份，副标题按该月 1 号更新。
- S3 点「今天」回到本月，副标题为今天的值。
- S4 单测：1900–2100 年**每一天**生成副标题，找出最宽的文案，e2e 用真实翻月到能显示该文案的路径核对不截断、不与按钮重叠（宽度实测）；只在无法用真实路径显示时才允许注入，并在注释说明原因。
- S5 原有 npm test 与 e2e 全部通过；截图 07/08 的标题与副标题内容一致。
