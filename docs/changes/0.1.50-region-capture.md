# 0.1.50 框选收纳（老板 02:07，参考 EasyLens feat/gbot 分支的 Electron 透明窗体；PM 02:08 定形态）+ 快捷键改键

## 判断
- 框选拿到的是屏幕像素：收进来是一张图片，不是原文、链接或格式。所以它和「复制后 ⌃⌥V」是互补，不是替代：
  - 能复制的内容（网页图文、链接、文字）→ ⌃⌥V，保留真内容。
  - 复制不了或不想复制的（视频画面、禁止复制的应用、一块界面、聊天记录一屏）→ 框选。
- 技术路线与 EasyLens 的 Electron 版一致：透明全屏窗体 + desktopCapturer 截取；需要 macOS「屏幕录制」权限（EasyLens 已验证可行）。不需要辅助功能权限。
- 这一版不做文字识别（OCR）：中文识别要么包很大、要么要原生代码，放到之后单独评估。

## 交互
1. 快捷键 ⌃⌥A 启动（PM 02:08 定；coder 核实不与微信、QQ 截图冲突）。托盘右键菜单新增「框选收纳  ⌃⌥A」，在「收纳剪贴板内容」下方。
2. 在所有屏幕各铺一层透明置顶窗体（可跨屏起笔，框限定在起笔所在屏幕）：整屏压暗 20%，光标变十字，顶部居中提示「拖动框选要收纳的区域 · Esc 取消」。
3. 按住拖动画框：框内恢复原亮度，橙色 1.5px 边框，左上角外侧显示尺寸「480 × 320」。
4. 松手后在框下方（贴底时放框上方）弹出询问条「收纳这块？」+「收纳」（主按钮，回车）｜「取消」（Esc）。不满意直接在别处重新拖即可重画。这就是全局询问，不另弹系统对话框。
5. 点「收纳」：截取框内画面（Retina 按原分辨率），存为图片条目，透明窗体消失，菜单栏下方接纳框成功态「已收纳 · 框选图片」。
6. 列表里显示为图片：缩略图 + 副行「框选 · 来自 <启动前最前面的应用>」（取不到不写）。meta `via: "region"`。
7. 小于 8×8 的框视为误触，回到可画框状态。
8. 首次使用没有屏幕录制权限：不铺窗体，弹出栏历自己的说明卡「框选需要屏幕录制权限，用于截取你框住的那一块画面，不会上传」+「打开系统设置」按钮（直达隐私 › 屏幕录制）。授权后需重启栏历，说明卡写明。

## 改键（从 0.1.49 推迟）
- 设置 › 界面设置：「收纳剪贴板快捷键」「框选收纳快捷键」两行，各自可录入新组合、可清空；被占用时该行显示「快捷键被占用」。

- R-C1 ⌃⌥A 与托盘菜单都能进入框选；Esc、取消都能完全退出且不留窗体。
- R-C2 画框、尺寸标签、询问条位置（含贴底翻到上方）正确；回车 = 收纳。
- R-C3 收纳后图片尺寸 = 框尺寸 × 屏幕缩放比；条目 via=region，来源应用正确。
- R-C4 小于 8×8 不触发询问条。
- R-C5 无权限时出现说明卡，不铺窗体。
- R-C6 两个快捷键可改、可清空，立即生效。
- R-C7 截图（深、浅）：55-region-overlay、56-region-confirm-bar、57-region-permission-card、58-settings-shortcuts。
- R-C8 全屏应用（如全屏 Safari、视频）上按快捷键，透明窗体可见可用。
