# 0.1.57 收纳页「粘贴收纳」点了窗口不再收起 + 标签页删除按钮配色

老板反馈（2026-11-23 02:25 ET，0.1.56 已升级）：收纳页点「粘贴收纳」后，窗口因失焦隐藏了。
demo：不出。

## 根因（mind 读代码，coder 复现确认后可补充）
`captureFromPanel()` → `inbox:captureClipboard`（via:'panel'）→ `inbox-main.js captureClipboard` 里 `show({ keepCalendar:true })`
把**托盘下方的收纳提示框**（240×120，托盘下 6px，`computeDropzoneBounds`）弹出来。它正好盖在日历窗口顶部（「粘贴收纳」按钮所在区域）。
鼠标此时落在提示框上 → 日历页面收到 `documentElement mouseleave` → `pointer:leave` → `scheduleClose()` 200ms 后 `hideCalendar()`。
0.1.49 的 `keepCalendar` 只跳过了 `onShow` 那一次收起，挡不住这条 pointer-leave 路径。

## 锁定改法
| 入口 | 提示方式 | 窗口 |
|---|---|---|
| 收纳页「粘贴收纳」（via:'panel'） | **不再弹托盘提示框**；结果用窗口内的通用 `showToast` 显示：成功 `已收纳 · {label}`（success），重复 `{TEXT_CLIP_DUP}`（info），剪贴板为空或不支持 `{对应错误文案}`（warning），保存失败 `{errorText}`（error） | 未钉住时也保持打开；列表立即刷新，新条目在最上面 |
| 托盘菜单、快捷键、拖放（via:'tray'/'hotkey'/drop） | 不变，仍用托盘提示框 | 不变 |
实现：`captureClipboard` 在 via:'panel' 时不调用 `show()`/`send()`/`scheduleHide()`，只把 `{ok, text, label, count}` 返回给渲染进程，由 `captureFromPanel()` 调 `showToast`。文案沿用 inbox-main.js 现有常量，不新增文案。
