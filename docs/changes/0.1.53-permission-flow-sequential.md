# 0.1.53 屏幕录制授权：一次只出现一个框（老板 03:30 真机截图）

## 问题
0.1.51 的做法是按 ⌃⌥S 时先调一次 `getSources` 让系统登记栏历，如果仍未授权就弹栏历自己的说明卡。系统授权框是异步弹出的，栏历重新检查权限时用户还没点，所以检查结果还是「未授权」，栏历的说明卡就和系统框同时出现：两个框说的是同一件事，还叠在一起。这是 mind 契约的设计错误，当时的验收条目也没覆盖「系统框和说明卡同时在屏」这种状态。

## 改法（唯一方案）：按顺序，一次只出现一个框
1. 未授权时按 ⌃⌥S 或点托盘「框选收纳」：**只**弹栏历的说明卡。这时不调 `getSources`，系统框也就不会出现。
2. 说明卡文案（宽度不变）：
   - 标题：需要屏幕录制权限
   - 正文：框选收纳要截取你框住的那一块画面，不会上传。
   - 步骤：点「去授权」，在「屏幕录制」列表里打开「栏历」，再按提示重新打开栏历。
   - 按钮：以后再说｜去授权（主按钮，回车）。按 Esc 等同「以后再说」。
3. 点「去授权」：
   - a. 先关掉说明卡；
   - b. 调一次 1×1 的 `getSources` 让系统登记（超时 1500ms，超时或报错只记日志）；
   - c. 再查一次权限。已授权就直接进框选层；仍未授权就打开「屏幕录制」设置页。第一次授权时，系统框会盖在设置页上面，两者指向同一个开关，这是 macOS 的原生行为，可以接受。
4. 已授权时行为不变，直接进框选层。
5. 日志：`[栏历] 框选：说明卡 → 去授权 → 登记截屏 → <status> → 打开设置|进入框选`。

## 验收（每条都要截图或断言）
- Q-C1 e2e：权限设为 denied 时按 ⌃⌥S，说明卡出现，并且 `probeCalls === 0`。
- Q-C2 e2e：点「去授权」后，说明卡窗口已关闭，`probeCalls === 1`，`openCalls === 1`，顺序是先关卡、再登记、最后打开设置（用调用顺序数组断言）。
- Q-C3 e2e：登记后权限变成 granted（用钩子模拟）时，直接进框选层，`openCalls === 0`。
- Q-C4 e2e：按「以后再说」和 Esc 都能关卡，`probeCalls === 0`，`openCalls === 0`。
- Q-C5 截图：57 号说明卡重拍深浅两套，按钮文案是「以后再说 / 去授权」。
- 真机（老板）：先在终端执行 `tccutil reset ScreenCapture app.lanli.LanLi` 清掉授权，再按 ⌃⌥S。
  - ① 屏幕上只出现栏历的说明卡；
  - ② 点「去授权」后说明卡消失，出现系统框和设置页，列表里有栏历；
  - ③ 打开开关、重新打开栏历后，按 ⌃⌥S 直接进入框选。

## 不做
不改签名（0.1.52 的指纹钉死不动），不轮询权限状态。
