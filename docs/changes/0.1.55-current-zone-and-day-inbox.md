# 0.1.55 世界时钟「当前时区」+ 日历收纳圆点可点进

老板原话（2026-11-21 20:43 ET）：把“本地”两个字改成“当前时区”，给它个不一样的颜色；20 号的点是什么？如果代表有收纳，让它能点进去。
结论：圆点 = 当天有收纳（0.1.44 起，`cell-inbox-dot`）。本版让它能点进去。demo：不出（文案 + 颜色 + 复用已有筛选）。

## A. 世界时钟「当前时区」
| 项 | 锁定值 |
|---|---|
| 文案 | `本地` → `当前时区`（`describeClockRelative` 的 isLocal 分支，其余分支不变） |
| 颜色 | 只给这 4 个字上色，城市名、时间不变；浅色 `#007aff`，深色 `#0a84ff`（系统蓝；面板里橙/红已被菜单栏标签、强调色、节日占用，蓝色不撞色） |
| 字号/字重 | 与其它副标签一致（10px），字重 600 |
| 实现 | 副标签加 class `is-current-zone`，颜色写在 CSS（深色走 `prefers-color-scheme: dark`） |
| 宽度 | 「当前时区」4 个汉字在 10px 下约 40px，副标签区不得省略号截断 |

## B. 日历收纳圆点可点进
| 状态 | 行为 |
|---|---|
| 点一个**未选中**、有圆点的日期 | 照旧：选中该日期，黄历跟随（不打开收纳） |
| 点**已选中**的有圆点日期（未选其它日期时，今天视为已选中） | 打开收纳页，时间范围筛选 = 该日（复用 0.1.46 `setInboxDay(key)`），顶部范围条显示该日与条数，× 可清除 |
| 点已选中但**无圆点**的日期 | 不变，无反应 |
| 悬停有圆点的日期 | 用现有提示气泡：未选中显示「收纳 N 条」；已选中显示「收纳 N 条 · 点击查看」 |
| 悬停无圆点日期 | 不出气泡 |
| 有圆点 + 已选中 | 鼠标为手型 |
| 从收纳页「‹ 返回」 | 回日历，清掉这次带入的日期筛选（下次从顶部收纳入口进来看到全部） |
| 当日收纳全删光 | 圆点消失（0.1.44 已有刷新逻辑），再点不打开 |

N = 该日收纳条数，与收纳页筛选后数量一致。

## 验收条目（契约测试）
- A1 纽约为当前时区时副标签文字为 `当前时区`；其它城市 0.1.54 的日期/快慢/时间相同逻辑全部不变（更新 tests/world-clocks.test.js 里的 `本地` 断言）。
- A2 `当前时区` 节点带 `is-current-zone`，浅色计算色 #007aff，深色 #0a84ff。
- B1 点未选中有圆点日期 → 只选中，收纳页不打开。
- B2 再点同一日期 → 收纳页打开，range = {from:key,to:key}，列表只含该日条目，范围条条数 = N。
- B3 今天有圆点且未选其它日期 → 点一次即打开。
- B4 无圆点日期点两次 → 不打开。
- B5 气泡文案两种状态各一条断言；无圆点不出气泡。
- B6 返回后 range 为 null。
