# 0.1.35 十一项打磨 · 契约

来源：老板 0.1.34 验收后的 11 条。构建走 GitHub CI；主力 MiMo Code。素材在 `docs/changes/0.1.35-assets/`。
不出 HTML 样稿：每条都在本文写死，预览图 `0.1.35-assets/preview.png` 只用于签筒。

## 锁定
1. **⚙︎ 设置按钮下沉**：根因是 0.1.34 的 `.settings-button{margin-top:10px;}`（升级页按钮与顶栏按钮撞了类名）。升级页按钮改用独立类名 `.settings-check-update`，顶栏样式恢复 0.1.33。
2. **签语断行**：签语有空格 → 在空格处断成两行（如「无事发生 / 就是好事」）；没有空格 → 放得下就一行，放不下用 `text-wrap: balance` 两行均分。任何一行不得只有 1 个字；最多 2 行，不出省略号。
3. **签筒图标**：按钮内联 `0.1.35-assets/qiantong.svg`（红漆金边签筒），显示 24×24（内联 SVG，不转 PNG，`#pop-stick` 要能单独做动画），取代 0.1.33 的线条 SVG。点击动画 400ms：签筒左右晃（沿用 almanac-shake），同时 `#pop-stick` 那根签上弹 6px 再落回。`prefers-reduced-motion: reduce` 时不动。悬停提示仍是「重新抽签」。
4. **下拉菜单**：「更多…」改为「全部设置…」。
5. **设置导航**：「‹ 返回」与第一项「界面设置」之间加 1px `--sheet-border` 分割线，上下各留 6px；返回和各导航项同高 30px、左对齐、`cursor: pointer`。
6. **设置内容区字号**：内容区所有文字 ≥ 12px，列表正文 13px。每页顶部有页标题（界面设置/黄历/天气/世界时钟/升级）15px、`font-weight: 600`，下方 1px `--sheet-border` 分割线，标题区高 36px。嵌入的三个面板去掉它们自己的小标题，只用页标题。
7. **钉住后的关闭图标**：× 的可见尺寸与下载、钉住图标一致（14×14 盒子，线条两端各内缩 3px，stroke 1.6）；钉住与否，⚙︎ 设置按钮位置不变。
8. **删掉黄历详情**：黄历卡不再可点，去掉「查看黄历详情」提示、标题风格名后面的 ›、悬停高亮和「今日黄历」面板及其代码/测试。「去定制 ›」悬停显示规则不变（选中日非今天时不显示）。
9. **世界时钟副行**：只显示时差「本地 / 快 N 小时 / 慢 N 小时 / 快 9 小时 30 分 / 时间相同」，**不再出现「明天 · 」「昨天 · 」**，一行放下不出省略号。
10. **天气间距**：当前温度与区间温度之间 8px 间距，区间用 `--muted` 11px。
11. **天气刷新**（定时 30 分钟不变，再加三条）：
    - 系统 `powerMonitor` 的 `resume` 和 `unlock-screen` 后 5 秒强制刷新一次。
    - 每次展开窗口时，若上次结果是失败或已超过 30 分钟，立即刷新。
    - 失败状态：卡上显示「天气暂不可用」+ 紧跟一个常显文字按钮「重试」；点「重试」只刷新（显示「正在刷新…」），不打开换城市，要阻止冒泡。失败结果不缓存；失败期间每 60 秒自动重试一次，成功即停。失败状态下不显示「更换 ›」，点卡片其他位置仍打开换城市。

## coder 可自主
实现方式、组件复用、动画曲线；签筒 SVG 可微调颜色细节但轮廓不改。

## 不做
主题色/深浅色；新增设置项；黄历卡其他布局。

## 验收（真点、真切换，期望值计算得出，不许写死）
- C1：顶栏 ⚙︎ 设置按钮的垂直中心与钉住按钮中心差 ≤ 0.5px，底边距顶栏底线 ≥ 4px；钉住后再测一次结果相同。
- C2：用测试钩子把 5 种风格的 60 句签语逐句渲染：每句 ≤ 2 行、没有任何一行只有 1 个字、不出省略号；带空格的签语第 1 行恰好是空格前的部分。
- C3：签筒按钮里有 `#pop-stick`，尺寸 24×24；点击后动画类出现，500ms 内移除；签语换成同风格另一句。
- C4：下拉菜单模板有「全部设置…」、没有「更多…」，点击进入设置页。
- C5：设置导航里「‹ 返回」和「界面设置」之间有分割线元素；返回与各导航项 computed `cursor` 为 `pointer`、高度 30px。
- C6：五个设置页逐一切换：页标题 15px 且 font-weight ≥ 600、有底部分割线；内容区内所有可见文字 computed font-size ≥ 12px。
- C7：钉住后 × 图标的 boundingBox 与未钉住时的钉住图标、下载图标宽高相等（±0.5px）。
- C8：点黄历卡任意空白处不出现任何 dialog；页面上没有 `aria-label="今日黄历"` 元素和「查看黄历详情」提示。
- C9：固定纽约 20:38 时，东京、北京行副文案不含「明天」「昨天」，等于按时差计算出的文案；每行 scrollWidth ≤ clientWidth。
- C10：天气卡当前温度右边缘到区间温度左边缘距离 8px（±1）。
- C11：①测试钩子触发 resume → 5 秒后（fake timer）weatherService.refresh 收到 force；②mock 天气失败 → 卡上出现「重试」，点击后 refresh 被调用且城市面板未打开；③失败后推进 60 秒自动重试一次，mock 成功后显示温度且不再重试；④失败状态悬停时不出现「更换 ›」，点卡片空白处仍打开城市面板；⑤失败结果不进缓存（再次 refresh 不加 force 也会发请求）。
- C12：现有单测和 e2e 全过（删掉的黄历详情相关用例一并删掉）。
