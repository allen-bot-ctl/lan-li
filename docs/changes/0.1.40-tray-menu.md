# 0.1.40 菜单栏右键菜单（对齐栏况 0.1.14）

需求（老板 2026-11-19 05:53）：栏历的菜单栏入口加右键菜单，和栏况一样。
不出样稿：系统原生菜单，文案和顺序即规格。

## 规格（唯一方案）
1. 右键（含 Ctrl+左键）菜单栏的栏历时钟，弹出系统原生菜单，从上到下：
   - `检查更新…`
   - `设置中心…`
   - 分割线
   - `退出栏历`，快捷键显示 ⌘Q
2. 实现：监听 `tray.on('right-click')`，用 `tray.popUpContextMenu(menu)` 弹出。
   不用 `tray.setContextMenu`，否则 macOS 左键也会弹菜单，悬停开日历的行为就坏了。
3. 右键时：日历窗口若已因悬停打开，先立即隐藏，再弹菜单；菜单开着期间悬停不再开日历。
   菜单关闭后，鼠标移出再移入时钟才重新按悬停开日历。
4. `设置中心…`：打开日历窗口并直接进入综合设置页（即现有 `sendPanel('settings')`），窗口保持打开，不因鼠标不在窗口上而自动关闭。
5. `检查更新…`：和第 4 条一样打开设置页，并立刻执行一次检查更新（现有 `requestUpdateCheck()`），检查结果显示在设置页的「检查更新」那一行，和在设置页里点按钮完全相同。
6. `退出栏历`：和现有退出走同一个函数（含兜底强退）。
7. 左键点击、悬停、日历窗口内的 ⚙ 设置菜单都不变。

## 验收（契约测试）
- C1 菜单模板顺序和文案正好是：检查更新… / 设置中心… / 分割线 / 退出栏历，退出项 accelerator 为 `CommandOrControl+Q`。
- C2 触发右键后日历窗口不可见，菜单已弹出；左键点击和悬停的现有 e2e 全部仍通过。
- C3 点「设置中心…」后窗口可见且当前面板为 settings。
- C4 点「检查更新…」后面板为 settings，且检查更新被调用一次。
- C5 点「退出栏历」调用退出。
- 闲置 CPU、菜单栏宽度检查不受影响。
