# 0.1.36 契约：设置页左上角对齐、天气长城市名、天气设置选中态

负责人：mind 写契约，coder 写代码。来源：老板 0.1.35 验收截图（左上角很尴尬），以及 mind 在 8067c9c 上的走查。不出样稿。

## 改动（唯一方案）
1. **左上角对齐**：现在左栏「‹ 返回」下面的分割线在窗口 y≈76，右边页面标题下面的线在 y=68，两条线不在同一高度，文字也不在同一条基线上。
   - 把 `.settings-nav` 的上内边距改成 0，即 `padding:0 6px 8px`。
   - `.settings-back` 的高度和行高都改成 36px，`flex:0 0 36px`。为了和右边标题对齐，左右内边距用 `0 10px`，左右外边距用 `0 -6px`，圆角为 0，悬停时整行出底色。
   - `.settings-nav-divider` 的外边距改成 `0 -6px 6px`，让它贯通左栏全宽，落在 y=68，和右边的线连成同一条横线。
   - 「返回」的字号用 15px、字重 600，和页面标题一样。
2. **右上角空位**：在设置视图里，`#settings-button` 从 `visibility:hidden` 改为 `display:none`，钉住和更新图标贴回右边。最右边的图标离窗口右边缘的距离要和主界面里 ⚙ 胶囊离右边缘的距离相同。
3. **天气长城市名**：渲染完天气卡后，如果 `#weather-city` 的 `scrollWidth > clientWidth`，就给卡片加上 `.is-compact`，隐藏 `.weather-range`。隐藏后如果还放不下，才显示省略号。每次渲染天气或切换城市时都重新判断。
4. **天气设置选中态**：在设置页内嵌的天气选择器里，当前城市所在的行，或者没有手动城市时的「自动（按 IP）」行，按黄历设置页 N6 的方式显示：`is-selected`，底色 `--chip-hover`，右侧用 `--accent` 显示 ✓，去掉「已选」两个字。这一行仍然可以点，不显示成灰色禁用。「自动（按 IP）」行的左边缘要和搜索框的左边缘对齐，相差不超过 1px。

## 验收（e2e 自动化）
- C1：在设置视图里，左栏分割线和右边标题下线的 y 坐标相差不超过 0.5px；「‹ 返回」和页面标题的文字中心相差不超过 1px。浅色和深色模式各截一张图。
- C2：在设置视图里，`#settings-button` 计算出的 display 为 none；最右边图标的右边距和主界面里 ⚙ 胶囊的右边距相差不超过 1px。
- C3：模拟城市为「Los Angeles」、天气为 `18° 14°~20°` 时，卡片有 `.is-compact`，区间被隐藏，城市名完整显示（`scrollWidth <= clientWidth`）；城市为「北京」时区间照常显示。
- C4：在天气设置页，当前城市所在行带有 `is-selected` 和 ✓，没有「已选」，按钮不是禁用状态；没有手动城市时，「自动（按 IP）」行是选中状态。
- C5：原有的单元测试和 e2e 全部通过。

## 不做
不改主界面的顶栏，不改窗口尺寸，不动其他设置页的内容。
